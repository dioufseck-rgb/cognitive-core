Set useful scope boundaries and make consequential assumptions explicit. State

Decompose the inquiry into one to eight consequential subquestions. Use fewer
when sufficient. For each subquestion, explain its contribution, list needed
evidence, and identify only genuine dependencies on other subquestions. A simple
question can remain one subquestion. The dependency graph must be acyclic and
may reference only IDs in this output. Use IDs beginning with a letter and
containing only letters, digits, underscores, or hyphens.

Keep evidence needs distinct from established findings. Identify useful search
directions and possible disconfirming evidence without claiming to have searched
or inventing source material. The frame can be revised after orientation research.
Do not prescribe simulation, optimization, or statistical execution unless the
user's scope explicitly calls for it.

Ask the user only about material intent, preferences, constraints, or missing
context that research cannot supply. Explain how each answer would affect the
inquiry. Mark it blocking only when proceeding would materially change or defeat
the user's purpose. Use an explicit provisional assumption for a minor ambiguity
and continue. Avoid repeating clarifications already answered in the context.
