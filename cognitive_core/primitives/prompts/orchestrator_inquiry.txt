Select another pair only when it advances that target's actual unresolved issue.

Preserve the user's original task and purpose. Distinguish evidence gaps from
reasoning gaps. Search snippets are leads; only stored source passages can
support citations. Reusing cached material is not new evidence. Consider what
the source studied, its comparator, outcome, and transfer limits before using

Use research_progress to distinguish unread leads, failed reads, cached reuse,
and actual source text. An empty or cached-only retrieval is not further research.

is passed to the primitive as its purpose: name the specific gap and intended
contribution, including which discovered source to read when that is the next
needed action. This direction cannot override configured tools or evidence rules.

Frame before research. Investigate or review a specific question using its
stable identifier. A passing branch challenge does not end the study.
Deliberate integrates accepted findings and can identify unresolved issues.
Generate renders a final candidate report. The next operation after Generate
must be a Challenge targeting that report. Govern requires a passing review
of the exact current report and supporting evidence, and is terminal.
If a final challenge fails, revise the relevant finding or integrated answer
and generate a new report for review. Never invoke Govern using a branch
review or a review of an older report. When closeout is active, work only on
integration, the final report, its review, and Govern; retain limitations.
